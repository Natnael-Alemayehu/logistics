# AGENTS.md

## Project

Kiflet: offline-first shipment tracking and proof of delivery for Ethiopian
trucking companies. See `README.md` for what it does and how it fits together.

- `docs/functional_requirements.md`: the original requirements (FR numbers
  are referenced in code comments). Appendix D records where the product
  deliberately differs; add to it when you depart from a requirement.
- `docs/logistics.md`: background on the problem
- `docs/E2E_TEST_GUIDE.md`: manual walkthrough of every flow
- `docs/deploy.md`: production, backups, staging, connecting the providers
- `docs/audit-2026-11.md`: the audit of November 2026 and its fix record
- `CONTRIBUTING.md`: these rules at full length
- `ROADMAP.md`: what comes next, in order. Delete a section once it is done.
- `CHANGELOG.md`: what changed in each release. It is the only file that
  may name what the product was called before; CI checks.

## Architecture

One Go application. It serves the dispatcher dashboard
(server-rendered `html/template`), the public tracking pages, the driver PWA
(`internal/web/static/driver`) and its JSON API, and runs the background jobs.
There is no separate frontend or mobile codebase. The Next.js and Expo apps
were retired and live only in git history.

- `internal/app`: builds the app from its settings (providers, services, web
  server, background workers). `cmd/server` and the integration tests both
  use it, so new wiring goes here, not in `main.go`.
- `internal/web`: routes (`server.go`), middleware, handlers (`app_*.go`,
  `public.go`, `api_driver.go`, `api_public.go`), templates and static files
- `internal/service`: all business rules. Handlers stay thin.
- `internal/model`: statuses and the transition table, reasons, roles, plans
  and prices
- `internal/text`: the words customers read, in English (`en.go`) and
  Amharic (`am.go`)
- `internal/db`: generated by sqlc from `sqlc/queries`. Don't edit by hand;
  run `make sqlc`.
- `internal/sandbox`, `cmd/sandbox`: the provider sandbox, a separate service
  playing Ethio telecom, telebirr and CBE Birr for the real adapters
  (`make sandbox`, `make run-sandbox`)
- `migrations`: goose migrations, embedded and applied on start

## Working on it

Run commands from the repository root.

```bash
make db && make seed && make run   # http://localhost:8080, demo logins in README
make test                          # unit tests
make test-integration              # HTTP-level tests against PostGIS
make staging-up && make test-e2e   # production's images and compose file, over HTTPS
make vet
make lint                          # golangci-lint, node --check, gitleaks over the history
```

- Templates are reloaded from disk with `DEV_RELOAD=true` (`make run` sets it),
  but template errors only show at render time. `go test ./internal/web/`
  parses every page.
- The CSP is `script-src 'self'`, so no inline scripts. Pass data to JS through
  `<script type="application/json">` blocks or `data-` attributes.
- Every query is scoped by tenant. Keep it that way in new queries.
- What a customer reads (their texts, the tracking and confirmation pages)
  comes from `internal/text`, in English and Amharic: add the words to
  `en.go` and `am.go`, and use `{{.T "key"}}` in the template. Tests check
  that the two files match and that templates name only keys that exist.
- Metrics live in `pkg/metrics`. Label them by route pattern or another short
  fixed list, never by company, user or shipment ID.
- `audit_logs` and `shipment_events` are append-only: a trigger rejects
  UPDATE, DELETE and TRUNCATE. Code that must remove them (company deletion,
  retention) runs inside `purgeTx` in `internal/service/data.go`, which sets
  `kiflet.purge` for its transaction only.
- The public API (`api_public.go`) acts as its key's `service.Actor`
  through the same services as the dashboard; it has no rules of its own.
  `static/openapi.json` describes it, and `TestOpenAPIMatchesTheAPI` checks
  that the two have the same routes and fields: change them together.
- Webhooks are written in `ShipmentService.event`, with the shipment's
  history: a new kind of event reaches them by adding it to
  `webhookTypes` in `internal/service/webhooks.go`. Their payload is the
  API's `ShipmentJSON` and `EventJSON` (`internal/service/api_json.go`).
- The driver app's status rules come from `/api/v1/driver/config`, which is
  derived from `model.AllowedTransitions`. Change the rules there, not in JS.
- The driver app is ES modules with no build step. `app.js` starts it;
  what several modules change lives in `S` (`state.js`), since a module
  can't assign to another's variables. A new module needs a
  `<link rel="modulepreload">` in `driver/index.html`; `TestDriverBuild`
  checks.
- The driver app's service worker installs every file under
  `static/driver` as one version, listed in `/driver/build.json`
  (`internal/web/driver.go`), so a new file needs no list there. A deploy
  reaches a phone the next time the app starts after downloading it.
- Live updates: an element with `data-live-region` and an `id` is fetched
  again and swapped in when a WebSocket message says something changed
  (`static/app.js`). Mark new live parts of a page that way instead of
  rendering them in JS.
- Page stylesheets (the `head` block, e.g. Leaflet's) load before `app.css`,
  so `app.css` can restyle vendor widgets.
- The sandbox imports only the standard library and `pkg/console` (a test
  enforces it): it implements the providers' side of each contract on its
  own. When a contract changes or is confirmed with a provider, change the
  adapter (`pkg/sms`, `pkg/payments`) and the sandbox together, and run
  `make test-integration`, whose sandbox tests run the adapters against it.
- Staging is `deployments/docker-compose.prod.yml` with
  `deployments/staging/compose.yml` on top, which only swaps in stand-ins for
  the outside world (the sandbox, Mailpit, SeaweedFS, Caddy's own CA). Change
  production's file and staging follows. `tests/e2e` runs against it; its
  last test restores a backup over staging's data.
- The Dockerfile and CI (`.github/workflows/ci.yml`) name the same Go
  release, the newest: change them together.
