Make a key

Name it after what will use it. What a key does is recorded under that name, in each shipment's history.

Using the API

Requests go to {{$d.BaseURL}}, in JSON. Each key may make 300 requests a minute.

  • Book, list, change and cancel shipments, and assign drivers.
  • Read a shipment's history and where its truck was last seen.
  • List your drivers.

Every endpoint and field is described in the OpenAPI document.

A key acts for the whole company, with the same rules as the dashboard. Keep it out of web pages and phone apps, where anyone could read it.
